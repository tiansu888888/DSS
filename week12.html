Week 12: Object Oriented Technologies & DSS Design (Part 1) 第 12 周：面向对象技术与 DSS 设计（一）

Step-by-Step Guide 分步指南

1. Object-Oriented DSS Development

Object-oriented technology maps system entities (such as users, models, and databases) into classes and objects. This simplifies DSS development by supporting encapsulation, inheritance, and code reusability.

2. UML Use Case & Sequence Diagrams

UML is used to model DSS structure and behavior: **Use Case Diagrams** illustrate system features and user actor interactions, while **Sequence Diagrams** show the chronological execution and message passing between object lifelines.

1. 面向对象 DSS 开发

面向对象技术将系统实体（如用户、模型和数据库）映射为类和对象。这通过支持封装、继承和代码可重用性来简化 DSS 的开发过程。

2. UML 用例图与顺序图

UML 用于对 DSS 结构和行为进行建模：**用例图**说明系统特征和用户参与者的交互，而**顺序图**显示对象生命线之间的按时间顺序执行的操作和消息传递。

Tips 提示

UML Diagramming: A Use Case represents a single system goal (e.g. Run Solver). Actors are outside the system boundary. In Sequence diagrams, focus on standard message flow arrows.
UML 建模图绘制：用例代表单个系统目标（例如运行求解器）。参与者在系统边界之外。在顺序图中，重点关注消息流向的物理或逻辑箭头。
