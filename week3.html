Step-by-Step Guide 分步指南

2.1 Phases of Decision Making Process

  • Intelligence Phase: Searching the environment to identify problem conditions or opportunities. Involves organizational objectives and problem classification.
  • Design Phase: Formulating, developing, and analyzing alternative courses of action. Involves building cognitive or mathematical models of the problem.
  • Choice Phase: Selecting the best alternative course of action from those developed in the design phase. Includes evaluation and risk analysis.
  • Implementation Phase: Putting the selected decision into action and tracking execution. Feedback loops return to previous phases if issues arise.

Real-world Case: Netflix

  • Intelligence: Netflix detects a drop in subscriber engagement in a specific genre.
  • Design: Content teams model alternative show concepts, target audiences, and budgets.
  • Choice: Executive algorithms select the project with the highest predicted ROI.
  • Implementation: Producing the show, launching it, and monitoring viewership logs.

Reference: How Netflix Uses Analytics to Select Movies

2.2 How Decisions are Supported

  • Supporting Intelligence: Supported by Data Warehouses, OLAP query systems, data mining, and web search filters to find root causes.
  • Supporting Design: Supported by mathematical modeling toolkits (such as Excel Solver), brainstorming tools, and simulation engines.
  • Supporting Choice: Supported by multi-criteria decision models, decision matrix calculators, and What-If analytics.
  • Supporting Implementation: Supported by reporting dashboards, communication modules, and project management portals.

Real-world Case: Uber

  • Intelligence: Surge pricing algorithms identify high demand spikes in specific zones using GPS telemetry.
  • Design: Surge simulators generate alternative price multipliers to balance demand.
  • Choice: Algorithms select the optimal multiplier that optimizes trip matching.
  • Implementation: Dynamic price is pushed to passenger and driver apps immediately.

Reference: Uber Real-Time Dynamic Matching Systems

2.3 Decision Support System Capabilities

  • Individual & Group Support: Assists individual managers as well as cooperative committees.
  • Sequence Decisions: Supports a series of interrelated choices made over time.
  • Model Integration: Provides direct access to mathematical, financial, and simulation models.
  • User Control: Gives decision-makers full control over the inputs and model selection.

Real-world Case: Ford Motor Company

  • Ford design engineers use collaborative design-support systems to model vehicle aerodynamics.
  • The DSS supports sequential choices (weight changes -> drag changes -> fuel changes) while giving the engineer final design approval.

Reference: Decision Intelligence at Ford Motor Company

Simon's Decision-Making Phases

Phase Objective IT Tool Support Real-World Example
1. Intelligence Identify the problem or opportunity Data queries, OLAP, web alerts, anomaly detection Detecting a sudden drops in store sales via sales dashboards
2. Design Formulate alternative courses of action Simulation models, brainstorming tools, forecasting Generating three alternative staffing schedules in Excel
3. Choice Select the best alternative from the options Decision matrices, optimization algorithms, solver Using linear programming solver to pick the highest profit mix
4. Implementation Execute the decision and monitor results Project management tools, KPI reports, follow-up logs Deploying the schedule and tracking weekly labor cost savings

The Choice Phase Support

During the Choice phase, DSS provides solvers and optimization algorithms to compare alternatives objectively, reducing cognitive bias and emotional decision-making.

2.1 决策制定过程阶段 (Herbert Simon)

  • 情报阶段 (Intelligence)： 搜索环境以确定问题条件或机会。涉及确定组织目标与问题分类。
  • 设计阶段 (Design)： 构思、开发和分析可能的备选行动方案。涉及建立问题的认知或数学模型。
  • 选择阶段 (Choice)： 从设计阶段开发的备选方案中选择最佳的行动方案。包括方案评估与风险分析。
  • 实施阶段 (Implementation)： 将所选决策付诸行动并跟踪执行情况。如果出现问题，反馈循环将返回之前的阶段。

真实企业案例：网飞 (Netflix)

  • 情报阶段： Netflix 检测到特定流派的订阅用户参与度有所下降。
  • 设计阶段： 内容团队针对备选剧集概念、目标受众和预算进行建模。
  • 选择阶段： 高管算法选择预测投资回报率 (ROI) 最高的项目。
  • 实施阶段： 制作剧集、上线并监控收视率数据。

参考链接： Netflix如何利用分析来选择电影

2.2 决策如何获得系统支持

  • 支持情报阶段： 通过数据仓库、OLAP 查询系统、数据挖掘和网页搜索过滤器来查找根源问题。
  • 支持设计阶段： 通过数学建模工具箱（如 Excel Solver）、头脑风暴工具和模拟引擎提供支持。
  • 支持选择阶段： 通过多准则决策模型、决策矩阵计算器和 What-If 分析提供支持。
  • 支持实施阶段： 通过汇报仪表板、沟通模块和项目管理门户提供支持。

真实企业案例：优步 (Uber)

  • 情报支持： 动态调价算法利用 GPS 遥测数据识别特定区域的高需求峰值。
  • 设计支持： 价格模拟器生成不同的价格倍数方案以平衡供需。
  • 选择支持： 算法选择最佳倍数，以最大化乘客和司机的匹配率。
  • 实施支持： 动态价格立即推送到乘客和司机端的应用界面。

参考链接： Uber实时动态匹配系统

2.3 决策支持系统 (DSS) 核心能力

  • 个人与团队支持： 既能协助单体管理者，也能支持合作型的决策委员会。
  • 序列决策能力： 支持随时间推移做出的一系列相互关联的选择。
  • 模型整合力： 允许直接调用数学、财务和模拟决策模型。
  • 用户控制权： 给予决策者对输入数据和模型选择的最终控制权。

真实企业案例：福特汽车 (Ford)

  • 福特设计工程师使用协同设计支持系统来对车辆空气动力学进行建模。
  • 该 DSS 支持序列选择（重量改变 -> 阻力改变 -> 燃油效率改变），同时赋予工程师最终设计决定权。

参考链接： 福特汽车公司的决策智能

西蒙决策制定阶段

阶段 核心目标 IT 工具支持 实际应用示例
1. 情报阶段 (Intelligence) 发现并定义问题或机遇 数据查询、OLAP、网页提醒、异常检测 通过销售仪表板检测到门店销售额突然下降
2. 设计阶段 (Design) 构想各种备选行动方案 模拟模型、头脑风暴工具、趋势预测 在 Excel 中生成三种不同的员工排班备选方案
3. 抉择阶段 (Choice) 评估方案并选出最佳方案 决策矩阵、优化算法、规划求解器 使用线性规划求解器选择利润最高的组合
4. 实施阶段 (Implementation) 执行决策并持续监控结果 项目管理工具、KPI 报表、跟踪日志 部署排班方案并追踪每周节省的人工成本

抉择阶段的支持

在抉择阶段，DSS 提供了求解器和优化算法，以便客观地比较各种方案，减少认知偏差和情感化决策。
