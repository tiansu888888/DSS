Week 9: User Interface 第 9 周：用户界面

Step-by-Step Guide 分步指南

1. UI Goals in Decision Support

The user interface is the window through which the user interacts with the DBMS and MBMS. Key design goals include: ease of use, consistency, flexibility, control, and reducing the cognitive load on the decision maker.

2. Dialog Styles and Mechanisms

Dialog styles determine how users enter commands and receive data: **Command-line** (text syntax), **Menu-driven** (selection list), or **Graphical User Interface (GUI)** (visual icons and windows). Prototyping tools like Figma/Draw.io help design mockups.

1. 决策支持中的用户界面目标

用户界面是用户与 DBMS 和 MBMS 交互的窗口。关键设计目标包括：易用性、一致性、灵活性、控制性以及减轻决策者的认知负荷。

2. 对话样式与机制

对话样式决定了用户如何输入命令和接收数据：**命令行**（文本语法）、**菜单驱动**（选项列表）或**图形用户界面 (GUI)**（可视化图标和窗口）。像 Figma/Draw.io 这样的原型设计工具有助于设计模型。

Tips 提示

During UI evaluation, prioritize layout hierarchy and visual contrast. In Web/DSS displays, ensure primary information uses high-contrast text to keep it legible.
在进行 UI 评估时，优先考虑布局层次和视觉对比度。在 Web/DSS 页面展示中，确保主要信息使用高对比度文本以保持清晰易读。
