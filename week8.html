Week 8: Model Components (Part 2) 第 8 周：模型组件（二）

Step-by-Step Guide 分步指南

1. What-If Analysis

What-If analysis is a structured technique evaluating how changes in input variables affect outcomes. Excel offers several tools: **Scenario Manager** (compares groups of inputs) and **Data Tables** (displays multiple outputs side-by-side).

2. Goal Seeking

While What-If analysis starts with changing inputs to observe outputs, **Goal Seeking** works in reverse. It calculates the necessary input value required to achieve a predefined, specific target output value.

1. 敏感性分析 (What-If)

敏感性/情景分析 (What-If) 是一种评估输入变量变化如何影响输出结果的结构化技术。Excel 提供了几种工具：**方案管理器**（比较成组的输入）和**数据表**（并排显示多个输出）。

2. 目标求解 (Goal Seeking)

情景分析是从改变输入开始以观察输出，而**目标求解 (Goal Seeking)** 的工作原理则相反。它计算实现预设的特定目标输出值所需的输入值。

Task 1: Excel PMT formula for monthly payment for 5% annual interest, 12 months, and 10000 principal. 任务 1: Excel PMT 公式：计算 5% 年利率、12 个月、10000 本金的月还款额。

=PMT(0.05/12, 12, 10000)

Task 2: SQL query to update interest rate to 0.06 in 'Parameters' table where Name is 'Interest'. 任务 2: SQL 查询：更新 'Parameters' 表中 Name 为 'Interest' 的利率值为 0.06。

UPDATE Parameters SET Value = 0.06 WHERE Name = 'Interest';

Task 3: Excel formula to find minimum value in cells C1 through C5. 任务 3: Excel 公式：寻找单元格 C1 到 C5 的最小值。

=MIN(C1:C5)
